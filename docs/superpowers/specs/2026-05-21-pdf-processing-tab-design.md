# PDF 处理标签页设计文档

## 概述

在 VibeOCR 中新增"PDF 处理"标签页，提供独立的 PDF 工具箱功能，支持：
- 对扫描件添加隐形文字层（OCR → 写入 PDF）
- 检测并删除已有的文字层（支持多层预览和选择性删除）
- 页面操作：单页/整体旋转、插入、删除、拖拽排序

## 技术选型

- **PDF 操作库**：PyMuPDF (fitz) — 单库覆盖渲染、旋转、插入、删除、文字层读写
- **OCR 引擎**：PaddleX（复用现有 OCRService），不使用 MineRU
- **新增依赖**：`pymupdf`

## 架构

新增三个模块，修改一个现有文件：

```
src/vibeocr/
├── models/
│   └── pdf_document.py          # PDF 文档数据模型
├── services/
│   └── pdf_service.py           # PDF 操作服务（PyMuPDF 封装）
├── views/
│   ├── tabs/
│   │   └── pdf_tab.py           # PDF 标签页主控件
│   └── pdf_preview_window.py    # 独立预览窗口
└── views/main_window.py         # [修改] 添加 PDF 标签页初始化
```

**层次关系**：
- `PdfTab`（UI 层）→ `PdfService`（服务层）→ PyMuPDF
- OCR 部分复用现有 `OCRService`
- `PdfTab` 不直接接触 PyMuPDF，所有操作通过 `PdfService` 完成

### 缩略图列表

- 固定宽度 200px 的 `QListWidget`，自定义 delegate 渲染页面缩略图 + 页码标签
- 支持多选（Ctrl/Shift）
- 右键上下文菜单（单页和批量操作）
- 拖拽排序调整页面顺序
- 双击缩略图弹出独立预览窗口

### 操作面板

分为三个区域：
1. **页面操作组**：旋转（单页/全部）、删除选中页、在选中页后插入
2. **文字层操作组**：添加文字层、删除文字层、预览文字层、页面文字层状态列表
3. **进度区域**：OCR 进度条 + 取消按钮（仅操作进行时显示）

### 预览窗口

独立的 `PdfPreviewWindow`（`QWidget` 或 `QDialog`），支持：
- 缩放（滚轮）和平移（拖拽）
- 显示单页 PDF 内容
- "删除文字层"预览模式下叠加半透明高亮

### 工具栏按钮状态

- 未打开文件时全部禁用
- 保存/另存为：有未保存修改时启用
- 添加文字层：扫描页（无文字层）时启用
- 删除文字层：检测到有文字层时启用

## 数据模型

```python
@dataclass
class TextLayerInfo:
    index: int                    # 层序号
    text_preview: str             # 前30字摘要
    char_count: int               # 字符数
    bbox: tuple[float, float, float, float]  # 覆盖区域 (PDF坐标)
    color_id: int                 # 预览高亮颜色编号

@dataclass
class PdfPageInfo:
    page_index: int               # 页码 (0起始)
    rotation: int                 # 当前旋转角度 (0/90/180/270)
    has_text_layer: bool          # 是否有文字层
    text_layers: list[TextLayerInfo]
    is_scanned: bool              # 是否为纯扫描页
    thumbnail: QPixmap | None     # 缓存的缩略图

@dataclass
class PdfDocument:
    file_path: str | None
    pages: list[PdfPageInfo]
    is_modified: bool
    render_dpi: int = 300         # OCR 渲染分辨率
    thumbnail_dpi: int = 96       # 缩略图渲染分辨率
```

## 添加文字层

### 流程

1. 用户点击"添加文字层"，弹出配置对话框：
   - 处理范围：全部页面 / 选中的页面 / 指定页码范围
   - 语言选项：复用现有 OCRPreferences 设置
2. 确认后逐页执行：
   - `PdfService` 将页面以 300 DPI 渲染为 numpy 数组
   - 传给 PaddleX `OCRService.recognize()` 拿到 `OCRResult`（含 `text_blocks` + bbox）
   - bbox 坐标反算：`pdf_coord = pixel_coord * 72 / 300`
   - 用 PyMuPDF 在页面上方写入隐形文本（透明字体、不可见但可选中/可搜索）
3. 每完成一页更新进度条和缩略图文字层状态图标
4. 完成后标记文档已修改，启用保存按钮

### 分辨率处理

- 缩略图渲染：96 DPI（低内存，够缩略图用）
- OCR 渲染：300 DPI（标准 OCR 分辨率）
- bbox 反算公式：`pdf_coord = pixel_coord * 72 / render_dpi`

## 删除文字层

### 流程

1. 用户点击"删除文字层"
2. `PdfService` 解析每页内容流，识别文本绘制指令（`BT...ET` 块），按连续性分组为不同文字层
3. 进入预览模式：
   - 缩略图/预览窗口上叠加半透明色块，不同层用不同颜色
   - 右侧面板列出检测到的层：颜色标记、文本摘要、字符数
   - 用户勾选要删除的层
4. 确认后执行删除，标记文档已修改

### 多层处理

- 连续的 `BT...ET` 块算一层
- 每组独立识别、独立高亮、可单独删除
- 能区分扫描图像层和 OCR 文字层

## 保存

- **保存**：覆盖原文件，保存前创建 `.bak` 备份，成功后删除备份
- **另存为**：弹出文件对话框选择保存路径
- 文件被占用时提示"另存为"

## 错误处理与边界情况

- **大文件**：缩略图按需渲染 + LRU 缓存（最多 50 张），OCR 逐页处理不预加载
- **撤销**：不实现 undo/redo，旋转和删除操作前弹窗确认，文字层操作前提醒先备份
- **加密 PDF**：提示"不支持加密文件"
- **损坏 PDF**：捕获 PyMuPDF 异常，提示错误信息
- **OCR 未就绪**："添加文字层"按钮置灰，hover 提示
- **OCR 出错**：跳过当前页继续，汇总报告失败页数
- **取消 OCR**：已完成页保留，停止后续处理

## 标签页插入位置

在 main_window.py 的 `_setup_ui` 中，插入到设置页之前（与二维码标签页同方式），标签名"PDF 处理"。
