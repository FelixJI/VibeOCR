# Windows 平台能力 spike 人工检查清单

每个环境单独记录日期、操作者、OS build、显示器拓扑和结果。不得用 Win11 结果代替 Win10 1809。

## 环境矩阵

- [ ] Windows 10 1809 x64，Windows App Runtime 2.2，WebView2 Evergreen，.NET Desktop 10。
- [ ] 当前受支持的 Windows 11 x64，同上。
- [ ] 至少两台显示器，其中一台位于主屏左侧或上方，形成负虚拟桌面坐标。
- [ ] 分别验证 125%、150%、200% 缩放；至少一次混合 DPI 组合。

## 单实例与参数转发

- [ ] 启动首个 WinUI 实例，确认首窗可见。
- [ ] 从含空格、中文路径启动第二实例并传入待打开文件。
- [ ] 第二实例退出，首实例收到完整参数且只处理一次。
- [ ] 首实例退出后可再次正常成为 primary。

## 全局热键

- [ ] 注册默认截图热键并触发一次。
- [ ] 用另一程序占用同一热键，确认显示冲突而不覆盖对方注册。
- [ ] 修改热键后旧注册释放。
- [ ] 退出应用后原热键可由其他程序立即注册。

## 托盘

- [ ] 显示图标、提示文本和菜单，单击/双击行为符合设计。
- [ ] 隐藏/显示窗口不会重复创建托盘图标。
- [ ] 正常退出与异常窗口关闭后托盘图标均被移除。
- [ ] Explorer 重启后按后续产品策略恢复图标；不得遗留幽灵菜单或句柄。

## 截图与 DPI

- [ ] 在主屏、负坐标副屏和跨屏区域分别截图。
- [ ] 125%、150%、200% 下选区边界与像素内容一致，无一像素外的系统性偏移。
- [ ] 混合 DPI 跨屏选择时，物理矩形不裁切、不镜像、不缩放两次。
- [ ] BGRA descriptor 的 width、height、stride、pixel format、size、SHA-256 正确。
- [ ] 连续截图 100 次后 GDI object、handle 与共享内存映射无持续增长。

## 数据边界

- [ ] 全部 spike 使用 `winui-dev` profile。
- [ ] 正式 config、models、output 的内容与 mtime 前后不变。
- [ ] 日志和人工记录不包含用户名、token 或隐私绝对路径。
